### `01 / whoami`

I'm Michael, a Data Science graduate from **Universitas Pembangunan Nasional “Veteran” Jawa Timur**, based in Jakarta, Indonesia.

I clean datasets, explore business questions with SQL and Python, and build dashboards that help readers understand the results. My interests span customer behavior, retail performance, and the decisions behind business metrics.

I'm also learning how to work with AI in research, analysis, and software development, including how to check its suggestions.

### `03 / how I approach data`

```text
question
  |
  +-- source ....... understand origin, scope and gaps
  +-- clean ........ check types, duplicates and missing values
  +-- model ........ define grain, joins and business metrics
  +-- analyze ...... compare patterns and test explanations
  '-- communicate .. explain findings and their limits
```

### `04 / learning with AI`

I use AI to explore ideas, work through unfamiliar code, and iterate on projects. I'm learning to give it clearer context, evaluate its output, and recognize when I need to return to the source data or documentation.

```text
~/learning
|
+-- AI-assisted development
|   '-- plan -> build -> test -> review
|
+-- Prompting and context
|   '-- clear questions, useful examples, explicit constraints
|
'-- Output verification
    '-- inspect sources, check calculations, run the code
```
