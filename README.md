## `operating-protocol`

```text
[01] Start with the business question.
[02] Keep the source and transformation trail visible.
[03] Separate observed facts from derived values.
[04] Leave unknown values unresolved.
[05] Test the analysis and the interface.
[06] Write for the person making the decision.
```
